This is an example blog post written in MDX format. MDX allows you to use JSX components right in your markdown content. Notice the **Table of Contents** on the right side that auto-generates from the headings below!

## What is MDX?

MDX is markdown for the component era. It lets you write JSX embedded inside markdown. That's a great combination because it allows you to use markdown's often terse syntax (such as # heading) for the little things and JSX for more advanced or reusable components.

## Writing Your First Post

To create a new blog post:

1. Create a new `.mdx` file in the `content/blog` directory
2. Add frontmatter at the top with post metadata
3. Write your content using markdown and JSX
4. Your post will automatically appear on your blog!

### Frontmatter Example

```yaml
---
title: "My Blog Post Title"
description: "A brief description of your post"
date: "2025-10-15"
author: "Your Name"
tags: ["Tag1", "Tag2"]
# Optional: Add a cover image
image: "/blog/my-post-image.jpg"
imageAlt: "Description of the image"
---
```

### Adding Images

To add a cover image to your blog post:

1. Place your image in the `public/blog/` directory
2. Add the `image` field to your frontmatter: `image: "/blog/your-image.jpg"`
3. Optionally add `imageAlt` for accessibility

If you don't add an image, a nice placeholder will be shown instead!
